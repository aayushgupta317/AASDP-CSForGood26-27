Rules
To prevent code conflicts, your team should avoid pushing directly to the main or master branch. Instead, use the standard feature-branch workflow:
Step	Action	Git Command
1. Update Local Files	Pull the latest changes from the remote repo before starting.	 Type git pull origin main
2. Create a Branch - create and switch to a separate branch for your specific feature.	Type git checkout -b feature-name
4. Save Changes	Stage and commit your modified files locally. type	git add . git commit -m "Add feature info"
5. Push the Branch	Push your feature branch up to the remote GitHub repository.	git push origin feature-name
6. Pull Request (PR)	- Open a Pull Request on GitHub to propose merging your branch into main.	Done via the GitHub website
7. Review & Merge	Team members review the code, leave comments, and merge it if approved.	Done via the GitHub website
